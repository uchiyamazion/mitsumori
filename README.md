# 見積作成（GitHub Pages + GAS）

## 1. GAS（バックエンド）
1. 新しいGoogleスプレッドシートを作成 → 拡張機能 → Apps Script
2. `Code.gs` の内容を貼り付け、先頭の `TOKEN` を任意の文字列に変更
3. 関数 `setup` を1回実行（権限を承認）→ シート `単価_EHP` `単価_GHP` `出張料` `見積` が作成され、価格表が投入される
4. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」／実行ユーザー「自分」／アクセス「全員」→ URLをコピー

## 2. GitHub Pages（フロント）
1. `index.html` の `API` を上記URLに置換
2. リポジトリ（例: `uchiyamazion/mitsumori`）に `index.html` を push → Settings → Pages で公開
3. 初回アクセス時にアクセスキー（`TOKEN`）を入力（ブラウザに保存）

## 運用
- 単価の変更はスプレッドシートの `単価_*` `出張料` を直接編集（再読み込みで反映）
- 保存した見積は `見積` シートに1行ずつ保存（見積Noは `yyyymmdd-連番` で自動採番）
- Code.gs を修正したら「デプロイを管理」から新バージョンで更新
